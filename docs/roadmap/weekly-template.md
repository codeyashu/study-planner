# Weekly rhythm (~13–14.5 h)

| Day | Slot 1 | Slot 2 | Slot 3 | Slot 4 | Total |
|---|---|---|---|---|---|
| **Mon** | System design 45m | DSA 25m | Python rep 20m | | 1h30 |
| **Tue** | Agentic AI 60m | DSA 30m | | | 1h30 |
| **Wed** | Architecture 45m | DSA 25m | Python rep 20m | | 1h30 |
| **Thu** | Agentic AI 60m | Java/Spring AI 30m | | | 1h30 |
| **Fri** | System design 45m | DSA 25m | Python rep 20m | | 1h30 |
| **Sat** | **Agentic AI build 120m** | Java/Spring AI 30m | DSA 30m | | 3h00 |
| **Sun** | System design write-up 45m | ADR 30m | Staff+ 30m | Review 60m | 2h45 |

| Track | h/week | Rhythm |
|---|---|---|
| Agentic AI | 4 | two learning sessions + a Saturday capstone build (eval-first) |
| System design (+ AI SD) | 2.25 | two concept sessions + a Sunday written design |
| DSA | 2.25 | 5 sessions, pattern-based; re-solve on days 1/3/7/21 |
| Architecture | 1.25 | one concept session + one ADR per week on the capstone |
| Python | 1 | three 20-min expert reps |
| Java/Spring AI | 1 | ports the week's AI build to Spring AI |
| Staff+ | 0.5 | one artifact every ~2 weeks |
| Review | 1 | flashcards, explain-it-back, retro; mock interview on checkpoint weeks |

**Light weeks** (6, 12, 18) are about 65% of normal. **Buffer weeks** (25–26) are for catch-up and specialisation.

!!! tip "When life happens"
    Missed a day? Don't double up. Unfinished tasks appear under **Catch-up** on [Today](../today.md) for 7 days; do the P0 ones first. The Sunday agent rebalances if you're more than 3 days behind.
