# Daily digest

Written every morning (~06:15 IST) by a scheduled Claude agent following [AGENTS.md §6.1](https://github.com/codeyashu/study-planner/blob/main/AGENTS.md). Each post has 3–5 must-reads matched to *today's* topic, notable releases, a question of the day, and a tip for today's task. For the unfiltered stream, see the [feed](../reading/feed.md).
